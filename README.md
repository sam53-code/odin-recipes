# Odin Recipes

A simple recipe website created as part of The Odin Project curriculum.

## About

This project is my first Odin Project assignment. It was built using HTML only and focuses on creating multiple web pages that are connected using relative links.

The website includes:

* A main homepage
* Multiple recipe pages
* Relative links for navigation between pages
* Recipe ingredients and preparation steps
* Basic HTML structure and semantic elements

## Technologies Used

* HTML5

## What I Learned

Through this project, I practiced:

* Creating and structuring HTML pages
* Using headings, paragraphs, lists, and images
* Creating links with relative paths
* Linking multiple web pages together
* Organizing files in a project directory

## Project Status

Completed as part of the Foundations course in The Odin Project.
